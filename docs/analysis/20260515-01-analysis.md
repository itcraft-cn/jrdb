# 问题分析报告

## 问题概述

为 jrdb 添加注解 SQL 能力，实现混合模式（MyBatis Style + Hibernate Style + Jdbc Style），降低 CRUD 编码强度。

## 问题类型

新功能开发

## 目标定义

### 核心目标

1. 提供 MyBatis 风格的注解 SQL（`@Select/@Update/@Insert/@Delete`）
2. 提供 Hibernate 风格的实体查询（HQL-like）
3. 提供 Jdbc 风格的直接 SQL（默认）
4. 支持 AutoCrud 自动生成基础 CRUD
5. 统一到 DAO 接口，使用动态代理 + ASM 实现

### 衡量标准

1. 单元测试覆盖率 >= 80%
2. 集成测试通过（H2 数据库）
3. 性能不低于 Session API（asm 查询）
4. API 易用性（用户定义 DAO 接口即可使用）

## 边界定义

### 包含范围

- DAO 接口注解定义
- 三种 Style 注解（`@MyBatisStyle/@HibernateStyle/@JdbcStyle`）
- AutoCrud 注解（自动生成 insert/update/delete/selectById/selectAll）
- DaoProxyGenerator（ASM 生成代理类）
- DaoRegistry（DAO 注册表）
- DaoMetaCache（元数据缓存）
- StyleExecutor 接口及实现类
- 单元测试
- 集成测试

### 不包含范围

- Annotation Processor（编译时生成）
- 复杂查询生成（如 Query By Example）
- 分页查询注解
- 复杂参数绑定（如 Map/List 嵌套）
- Spring Boot Starter 集成（后续单独实现）

## 技术约束

### 技术栈

- Java 8+
- ASM 9.x（现有依赖）
- H2 2.x（测试数据库）
- JUnit 5（测试框架）

### 兼容性要求

- 与现有 Session API 平级，不破坏现有功能
- 兼容 jrdb-jdbc 和 jrdb-r2dbc（后续）

### 现有系统约束

1. Session API 是核心入口点
2. MapperRegistry 管理实体映射
3. MemoryPool 管理堆外内存
4. EntityMapper 是实体映射接口

## 风险识别

### 技术风险

1. ASM 字节码生成复杂度高，容易出错
2. 注解解析性能（首次调用）
3. 方法签名匹配（泛型、多参数）

### 业务风险

1. 用户学习成本（三种 Style）
2. API 设计不合理导致用户困惑

### 缓解策略

1. ASM 生成逻辑固化，复用现有 MapperClassGenerator 基础设施
2. 首次解析后缓存 DaoMeta，后续无解析开销
3. 单元测试覆盖各种参数签名场景
4. 提供 Demo 和文档，引导用户使用单一 Style

## 依赖识别

### 内部依赖

- Session API（jrdb-jdbc）
- MapperRegistry（实体映射）
- MemoryPool（堆外内存）
- TypeHandlerRegistry（类型处理）

### 外部依赖

- ASM（字节码生成）
- H2（测试数据库）

## 输出物定义

### 代码输出

#### 注解定义（jrdb-jdbc/annotation）

- `@MyBatisStyle` - 类/方法级别
- `@HibernateStyle` - 类/方法级别
- `@JdbcStyle` - 类/方法级别
- `@Select` - MyBatis 风格查询
- `@Update` - MyBatis 风格更新
- `@Insert` - MyBatis 风格插入
- `@Delete` - MyBatis 风格删除
- `@Query` - Hibernate 风格查询
- `@AutoCrud` - 自动 CRUD

#### 核心类（jrdb-jdbc/dao）

- `DaoProxyGenerator` - ASM 代理生成器
- `DaoRegistry` - DAO 注册表
- `DaoMeta` - DAO 元数据
- `DaoMetaCache` - 元数据缓存
- `MethodMeta` - 方法元数据
- `AutoCrudMeta` - AutoCrud 元数据
- `SqlParamBindStyle` - Style 枚举

#### 执行器（jrdb-jdbc/executor）

- `StyleExecutor` - 执行器接口
- `MyBatisStyleExecutor` - MyBatis 执行器
- `HibernateStyleExecutor` - Hibernate 执行器
- `JdbcStyleExecutor` - Jdbc 执行器

#### 配置扩展

- `JrdbConfig.Builder.defaultStyle(SqlStyle)` - 默认 Style 配置
