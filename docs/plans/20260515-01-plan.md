# 执行计划

## 计划概述

为 jrdb 添加注解 SQL 能力，采用 TDD 开发模式，分 6 个阶段实现：

1. Phase 1：注解定义 + 元数据模型
2. Phase 2：Style 执行器实现
3. Phase 3：DaoRegistry + DaoMetaCache
4. Phase 4：DaoProxyGenerator（ASM 生成）
5. Phase 5：AutoCrud 支持
6. Phase 6：集成测试 + 文档

---

## 验证策略

### 单元验证

- 每个类对应一个单元测试
- 测试覆盖率 >= 80%（使用 JaCoCo）
- Mock Session 依赖

### 集成验证

- 使用 H2 数据库
- 真实数据读写
- 完整 DAO 接口测试

### 端到端验证

- DAO 接口 -> ASM 代理 -> StyleExecutor -> Session -> JDBC
- 完整调用链测试
