# dbmmap 全局需求文档

## 项目愿景

dbmmap 是一个高性能数据库映射框架，通过堆外内存存储和 ASM 字节码生成技术，提供极致的查询性能，同时保持低 GC 压力和简洁的 API 设计。

## 核心需求

### 业务需求

#### BR-001: 高性能数据访问

**需求描述：** 系统需要提供比传统 ORM 框架更高的数据访问性能。

**业务价值：** 提升 OLTP 系统的响应速度，支持更高并发。

**验收标准：**
- 查询性能与 JDBC 直接访问相当
- 内存占用稳定，GC 压力低
- 支持大批量数据处理

#### BR-002: 低 GC 压力

**需求描述：** 系统需要避免大量临时对象对 JVM GC 的影响。

**业务价值：** 提升系统稳定性，减少 GC 停顿时间。

**验收标准：**
- 大数据量查询不触发 Full GC
- 内存使用可控可预测

#### BR-003: 简洁易用的 API

**需求描述：** 系统需要提供简洁直观的 API 设计。

**业务价值：** 降低学习成本，提高开发效率。

**验收标准：**
- 支持 try-with-resources 资源管理
- 支持 Builder 模式配置
- 支持 DSL 风格 SQL 构建

## 约束条件

### 技术约束

- 运行环境：JDK 8+
- 依赖 `sun.misc.Unsafe`
- 支持 MySQL/PostgreSQL 等主流数据库

### 设计约束

- 配置对象创建后不可修改
- Session 不是线程安全的
- MemoryBlock 需显式释放

## 质量属性

### 性能

- **目标：** 查询性能与 JDBC 相当，GC 压力显著降低
- **度量：** JMH 基准测试、GC 日志分析
